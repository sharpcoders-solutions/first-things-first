# first-things-first

Technical writing repository for a blog aimed at C# developers, covering a full career path from beginner to advanced. Posts are written in Markdown and versioned in Git.

## Overview

Each post is published in two languages, using the **same filename** in both folders:

- `posts/pt-br/` — Brazilian Portuguese (original)
- `posts/en-us/` — English (translation)

## How to use

1. Clone the repository.
2. Open the Markdown files in Visual Studio or your preferred editor.
3. Add new posts inside `posts/pt-br/` and `posts/en-us/`, using the same filename in both folders.
4. Keep the established personality/style: emoji section headers, 👉 callouts, ✅ checkmarks, a recap intro, and a "next step" teaser pointing to the following post.
5. Commit changes and publish through your usual Git workflow.
